## Apa itu Tailwind CSS

Tailwind CSS adalah kerangka kerja (framework) CSS berbasis utilitas yang digunakan untuk mendesain antarmuka (UI) situs web dengan cepat dan efisien langsung di dalam kode HTML.

## Kenapa Tailwind CSS

Tailwind CSS sangat populer dan banyak dipilih developer karena menggunakan pendekatan utility-first yang memungkinkan kita membuat desain UI modern dan unik dengan sangat cepat, tanpa perlu keluar dari file HTML/JSX atau memikirkan nama class CSS yang rumit.

## Syarat

Syarat utama belajar Tailwind CSS adalah menguasai dasar HTML dan CSS (terutama Flexbox, Grid, dan box model).

```
<script src="https://cdn.jsdelivr.net/npm/@tailwindcss/browser@4"></script>
```
